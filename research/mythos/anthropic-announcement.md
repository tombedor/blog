# Source Notes: Anthropic Project Glasswing Announcement

Source: https://www.anthropic.com/project/glasswing  
Date: April 7, 2026

## Key Facts

- Anthropic announced Project Glasswing as an initiative to secure critical software using **Claude Mythos Preview**.
- Launch partners: AWS, Anthropic, Apple, Broadcom, Cisco, CrowdStrike, Google, JPMorganChase, Linux Foundation, Microsoft, NVIDIA, Palo Alto Networks.
- Access extended to launch partners and **40+ additional organizations** that build or maintain critical software infrastructure.
- Anthropic committed **up to $100M in usage credits** and **$4M in donations** to open-source security organizations.
- Mythos Preview pricing for Project Glasswing participants: **$25/M input tokens** and **$125/M output tokens**.
- Anthropic says Mythos Preview is a general-purpose frontier model and its "most capable yet" for coding and agentic tasks.
- Distribution channels listed: Claude API, Amazon Bedrock, Google Cloud Vertex AI, and Microsoft Foundry.
