AI's impact on code quality is derided. But AI is a tool. Just as it can produce sloppy poorly thought out junk, it can fix bugs. And it is:

_google chrome bug graph_

Automated code review is _much_ better than I thought it would be. Some people complain about nitpicks. But _fixing nitpicks adds up_. 

I'm building a large project right now. It's more secure than it would be if I had written it by hand. It has security controls we wouldn't have been able to prioritize without AI.

Cybersecurity is just like any security market: it's a never ending contest between attackers and defenders. When I worked on fraud detection I used to say: there's job security. People are always going to steal.

In cybersecurity, attackers and defenders have the same job: use the best tools on the market find bugs. Attackers exploit, defenders repair. 



In this battle, the advantage isn't decided on the sophistication of cutting edge technology. The advnaage is how much power you have _relative to the other side_.

What then do Claude refusals, restrictions on open source models do? They distort the market of tools. You try to use Claude to talk cybersecurity _from an 14 year old enterprise financial institution_, but you might actually be an attacker, let's talk about something else. 

The defender abides by the rules, the attacker easily circumvents them. _Advantage attacker_
