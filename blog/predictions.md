# ai is more like an industrial revolution, social media was like the printing press

# how it's going to work
local

advances in server hardware flow to consumer machines

token subsidies will run out, smaller, specialized models will emerge. these will be primarily open source

datacenters in space:
- an elon pump, amplified by online followers and VC class that take his ideas seriously

# jobs
there was some quote by some entertainer about how he couldnt take a job because he'd know what his job is

it's a little rich for programmers to complain about automatino

the whole field changing below my feet was the large part of the appeal

things that ai can do will be abundant, the premium skill will be things that ai cannot produce on it's own
- either organic things, like art
- or things that ai can do only with a human's help

"you have to suffer" for a young person navigating ai is the most critical skill. the differentiator will be being able to leverage ai, while also engaging in productive struggle.


# failure modes
ecosystem

it is enourmously tempting to delegate all thought to ai. there will be many people who cease to actually *learn* anything at all.

it is also very tempting to fall for ai's tendency to flatter.
- this flattery is the new clickbait, the tugging of neurons that help control a user's behavior.

# programming languages

- code is cheap, languages that provide correctness rise
    - also a factor with security
- robust ecosystem less important: code is cheap!


virtuous cycle: make a change, observe against ground truth, react to feedback
